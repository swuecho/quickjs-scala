## Cross-Language Bytecode Execution

Make the QuickJS-Scala bytecode format language-agnostic, so interpreters in other languages can run bytecode generated by the Scala compiler.

### Why This is Powerful

- **Portability**: Run JavaScript on platforms without JVM (embedded, browsers, WebAssembly)
- **Performance**: Write optimized interpreters in Rust/C++ with JIT compilation
- **Language Interop**: Call JavaScript from Python, Rust, Go, etc.
- **Flexibility**: Different interpreters for different use cases (debugging, profiling, production)

### Real-World Examples

- **JVM**: Scala, Kotlin, Clojure compilers → same JVM bytecode → same Java Runtime
- **WebAssembly**: C++, Rust, Go compilers → WASM → any WASM runtime
- **Python**: PyPy runs CPython bytecode
- **Lua**: LuaJIT runs standard Lua bytecode

### Implementation Plan

#### 1. Define Stable Bytecode Format

Create a binary serialization format:

```scala
// Bytecode file format:
// Header:
//   - Magic number: 4 bytes (e.g., "QJBC")
//   - Version: 2 bytes
//   - Flags: 2 bytes
//   - Constant count: 4 bytes
//   - Code size: 4 bytes
//
// Constants section (variable length):
//   - Each constant: type tag (1 byte) + value
//
// Code section:
//   - Sequential opcodes with operands
//
// Example: PushI32(42)
// [opcode: 0x01] [operand: 0x2A 0x00 0x00 0x00]
```

#### 2. Add Bytecode Serialization

```scala
// In compiler module
object BytecodeWriter {
  def write(bytecode: Seq[Instruction], output: OutputStream): Unit = {
    // Write header
    output.write("QJBC".getBytes)           // Magic
    output.write(shortToBytes(1))           // Version
    output.write(shortToBytes(0))           // Flags

    // Write constants
    // Write code section
  }

  def toByteArray(bytecode: Seq[Instruction]): Array[Byte] = {
    val baos = new ByteArrayOutputStream()
    write(bytecode, baos)
    baos.toByteArray
  }
}
```

#### 3. Write Reference Interpreter in Another Language

Example in Rust:

```rust
// QuickJS bytecode interpreter in Rust
pub enum Opcode {
    PushI32 = 0x01,
    PushFloat64 = 0x02,
    Add = 0x03,
    Sub = 0x04,
    // ...
}

#[derive(Clone, Debug)]
pub enum JSValue {
    Int32(i32),
    Float64(f64),
    Bool(bool),
    String(String),
    Object,
    Null,
    Undefined,
}

pub struct Interpreter {
    stack: Vec<JSValue>,
    pc: usize,
    constants: Vec<JSValue>,
}

impl Interpreter {
    pub fn execute(&mut self, bytecode: &[u8]) -> Result<JSValue, Error> {
        loop {
            let opcode = bytecode[self.pc];
            self.pc += 1;

            match opcode {
                0x01 => { // PushI32
                    let value = i32::from_le_bytes(
                        bytecode[self.pc..self.pc+4].try_into()?
                    );
                    self.stack.push(JSValue::Int32(value));
                    self.pc += 4;
                }
                0x02 => { // PushFloat64
                    let value = f64::from_le_bytes(
                        bytecode[self.pc..self.pc+8].try_into()?
                    );
                    self.stack.push(JSValue::Float64(value));
                    self.pc += 8;
                }
                0x03 => { // Add
                    let b = self.stack.pop().unwrap();
                    let a = self.stack.pop().unwrap();
                    self.stack.push(add(a, b));
                }
                // ...
                0xFF => break, // Return
                _ => return Err(Error::InvalidOpcode(opcode)),
            }
        }

        Ok(self.stack.pop().unwrap())
    }
}
```

#### 4. Write a CLI Tool

```rust
// QuickJS bytecode runner in Rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let args: Vec<String> = std::env::args().collect();

    if args.len() < 2 {
        eprintln!("Usage: qjrun <bytecode.qjbc>");
        std::process::exit(1);
    }

    let bytecode = std::fs::read(&args[1])?;
    let mut interpreter = Interpreter::new();

    let result = interpreter.execute(&bytecode)?;

    println!("{:?}", result);
    Ok(())
}
```
